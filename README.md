# Sydney Housing Price Prediction and Decision Support System

Mini project: predict sold prices for properties in three contrasting Sydney suburbs (Mosman, Parramatta, Penrith) and serve the best model through a Streamlit app.

Live app: [Sydney Housing Price Predictor](https://s225099575-sydney-housing-prediction-decision-suppor-app-scrkz5.streamlit.app/)

## Contents
| File | Description |
|---|---|
| `data/sydney_sold_properties.csv` | 176 sold properties, collected manually from realestate.com.au |
| `sydney_housing_project.ipynb` | Full workflow and report text: cleaning, EDA, features, 3 models with 5-fold CV, error analysis, model export |
| `features.py` | Shared cleaning and feature engineering used by the notebook and the app |
| `app.py` | Streamlit app |
| `model.joblib` | Saved Ridge pipeline (regenerated by the last notebook cells) |
| `figures/` | Figures saved by the notebook |
| `requirements.txt` | Python dependencies |

## Data dictionary
`sale_price` (target, AUD), `sale_date`, `suburb`, `property_type`, `bedrooms`, `bathrooms`, `parking`, `land_size` (m², 0 for apartments/units/studios, blank if not listed), `dist_cbd`, and `dist_station` (km, suburb-level assumptions; excluded from the models because they duplicate `suburb`).

## Run it
```
pip install -r requirements.txt
pip install jupyter          # only needed for the notebook
jupyter notebook sydney_housing_project.ipynb   # run all cells to regenerate model.joblib
streamlit run app.py
```

## Deploy (Streamlit Community Cloud)
Push the repository to GitHub, go to share.streamlit.io, choose **Create app**, choose GitHub, select the repository, and set the main file to `app.py`.
